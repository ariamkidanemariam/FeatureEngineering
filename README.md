# Feature Engineering - Titanic Dataset

This repository focuses on data cleaning and feature engineering techniques using the classic Titanic dataset to prepare passenger information for machine learning models.

## Repository Structure

* `Feature Engineering.ipynb` — Main Jupyter Notebook detailing data analysis, feature creation, and engineering.
* `titanic.csv` — Primary Titanic passenger dataset.
* `Titanic_Ages_missing.csv` — Subset or specialized view tracking missing demographic data.
* `Titanic_Ages - Embarked.csv` — Cleaned reference mapping passenger age against embarkation details.

## Getting Started

### Prerequisites
Make sure you have Python 3 and Jupyter Notebook installed:
pip install jupyter pandas numpy matplotlib seaborn


### Running the Notebook
1. Clone or open this repository locally.
2. Launch the server in your terminal:jupyter notebook
3. Open `Feature Engineering.ipynb` to execute the code.

## Methods Used
* Data Cleaning & Handling Missing Values
* Feature Extraction & Engineering
* Exploratory Data Analysis (EDA)
